# 실제 카탈로그 구현 진행

최초 범위: 건물·구조물 33개와 식물 22종. 이후 사용자 피드백으로 두 진영의 구역 센터를 추가해 현재 57종(진영별 32/31개)이다.

1. 설치본 읽기 전용 추출 도구와 버전·해시가 기록된 카탈로그 생성.
   - 원본 참조/식별자/크기/번역 검증, 동일 입력 재추출 비교.
2. 실제/예시 프로필 및 진영별 정의, 저장·가져오기 호환 처리.
   - 예시 보존, 잘못된 진영·버전·종류 거부 테스트.
3. 실제 치수 도형, 출입구, 식물, 점유/표시 높이 분리와 표면 스냅 연결.
   - 원본 치수 및 출입구 회전, 플랫폼 적층, 식물 스냅 테스트.
4. 라이브러리·속성 패널에 분류/조건/출처와 편집기 한계 표시.
   - 진영별 31/30개, 농지 포함 파일 왕복, 좁은 창 확인.
5. 전체 테스트·빌드·브라우저 시각 검증 후 로컬 서버에서 사용 가능하게 제공.

게임 원본은 수정하지 않는다. 커밋·main 병합·푸시는 별도 요청 시 진행한다.

## 구현 결과 — 2026-10-01

- 1–4 완료: 전체 사실 자료 338개, 보조 정의 4개 제외 사유, 번역 누락 0개. 웹 활성 55종 및 진영별 31/30개.
- 기존 예시와 실제 데이터의 저장·종류·리비전을 분리. 처음에는 빈 실제 청사진을 연다.
- 계단/길의 표시 높이와 점유 높이 구분, 입구 위치·높이와 회전 반영. 식물은 기본 바닥 배치, 자동 적재 표면에서 제외.
- 데이터 재추출과 활성 목록 재생성 결과가 바이트 단위로 일치함을 확인. 원본 갱신 시 버전·해시 검토 없이 웹 카탈로그를 바꾸지 않도록 차단.
- 빌드 성공, 전체 테스트 27개 통과(데이터 계약 및 Edge 브라우저 회귀). 1440px / 600px 실제 카탈로그 화면 확인. 테스트 산출물은 `test-results/live-gallery.png`, `live-narrow.png`(Git 제외). 기존 500 kB 번들 크기 경고는 남아 있으며 빌드 실패는 아니다.
- 기존 Vite/TypeScript/Three.js 구조와 자체 도형을 유지. 별도 프레임워크·게임 에셋·생산 시뮬레이션을 추가하지 않음.
- 아직 미확인: 게임 안에서 실제로 따라 지을 때의 정확성/사용감, 대규모 도시 성능, 재배·지지·출입구·길 연결 규칙. 후속 목록 확장은 사용자 피드백 대기.

## 구역 센터 및 연결 표시 추가

마을 회관 요청에 따라 `DistrictCenter` 2개 정의를 활성화했다. 같은 원본 해시와 청사진 형식을 유지한다. 원본 경로 간선 기반의 계획용 연결 검사, 색 표시 토글, 선택/목록 상태와 요약을 추가했다. 회전·입구 높이·계단 방향·길 삭제/복원·센터 없음/여러 개·오류 저장본을 검사한다. 숨긴 층도 연결에 포함하며 지지·지형·구역 소속·게임 실제 통행 규칙은 미검증이다.
