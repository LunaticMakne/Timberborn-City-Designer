# Timberborn-City-Designer
팀버본 도시 디자이너

게임 옆에서 메가시티 청사진을 설계하는 웹 도구. 실제 게임 오브젝트를 배치하고 층별로 살펴보며, 같은 설계 데이터를 AI 에이전트와 함께 편집한다.

프로젝트 방향과 개발 순서는 [프로젝트 플랜](docs/PROJECT_PLAN.md)을 참고한다.

## 실행

Windows에서는 저장소의 **`start-designer.bat`을 더블클릭**하면 된다. 서버를 시작하고 `http://localhost:5173`을 기본 브라우저에서 연다. 이미 이 앱이 실행 중이면 기존 서버를 재사용한다. 새 서버의 실행 창은 사용 중 켜두고, 종료할 때 `Ctrl+C`를 누르거나 창을 닫는다. 다른 앱이 5173 포트를 사용 중이면 임의로 포트를 바꾸지 않고 오류를 표시한다. 패키지가 없는 최초 환경에서는 아래 설치 명령을 먼저 실행한다.

Node.js 24에서 확인했다. 저장소 폴더에서 실행한다.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 연다. PowerShell 이외의 환경에서는 `npm.cmd` 대신 `npm`을 사용한다.

## 현재 화면에서 가능한 작업

- 설치본 **1.1.2.4**의 57종(건물·구조물 35개, 작물·관목·나무 22종)을 배치한다. 구역 센터(마을 회관)를 포함하며, 공통 항목 포함 Folktails 32종, Iron Teeth 31종이다. 실제 카탈로그는 빈 설계로 시작하며, 데이터 세트에서 기존 예시도 따로 열 수 있다.
- 청사진을 3D / 위에서 보기로 탐색하고 카메라를 회전·이동·확대한다.
- 작업 화면 왼쪽 아래 **바닥 크기**에서 32·64·128·256칸으로 변경한다. 설치본 기준 기본 128, 최대 256칸을 적용했다. 새 실제 청사진은 128×128로 시작하며 기존 저장본은 원래 크기를 유지한다. 확장해도 배치 좌표는 그대로이고, 건물이 잘리는 축소는 막는다. 크기 변경도 저장·실행 취소할 수 있다. 최대 10,000개 한도를 넘기는 일괄 설치는 차단한다.
- 식물은 성장 시간·수확/채집량·수심/건조 조건을 속성 패널에서 확인한다. 생산·관개 시뮬레이션은 아니다.
- 구역 센터에서 길·계단을 통해 건물 입구까지 연결되는지 확인한다. **길 연결** 버튼으로 색 표시를 켜고 끈다(파랑: 센터 / 초록: 연결 / 주황: 끊김). 속성과 배치 목록에서도 상태를 확인한다. 회전·입구 높이·계단 방향을 반영하고, 플랫폼만 놓아서는 길로 취급하지 않는다. 센터가 없으면 미판정, 여러 센터가 있으면 어느 센터든 도달할 때 연결로 표시한다.
- 화면 기준 WASD를 누르고 있으면 연속 이동한다. 배치 중에도 사용할 수 있으며 입력창·도움말에서는 동작하지 않는다. 선택 도구의 왼쪽 드래그는 회전, 휠은 확대·축소다. 브라우저 제스처와 충돌하는 우클릭 이동은 사용하지 않는다.
- 줌 버튼 옆 이동 속도 슬라이더로 WASD 속도를 1×~3× 사이에서 0.25× 단위로 조절한다. 기존 속도가 최저·기본값인 1×이며, 설정은 청사진과 별도로 브라우저에 저장한다. 슬라이더 조절 직후에도 WASD로 이동할 수 있다.
- 라이브러리의 오브젝트를 골라 배치하고, 선택 항목의 좌표·높이·방향을 편집한다.
- 배치 도구에서 왼쪽 드래그로 사각형 영역을 미리 보고, 버튼을 놓으면 일괄 설치한다. 건물은 회전된 점유 크기 간격으로 반복한다. 드래그 시작 높이를 유지하며, 시작할 때 Shift를 누르면 지정 높이를 사용한다. 우클릭·Esc로 취소하고, 창 포커스를 잃거나 캔버스 밖에서 놓으면 설치하지 않는다. 겹침·범위 오류는 전체 설치를 막으며 실행 취소/다시 실행은 한 묶음으로 처리한다. 단일 클릭 배치와 선택 도구의 카메라 회전은 그대로다.
- 건물·플랫폼의 윗면을 가리키면 해당 표면 높이에 맞춰 배치한다. 커서 옆에 실제 배치 높이를 표시하며, Shift를 누르면 층 조절기로 지정한 높이에 고정한다.
- 배치 전에도 건물·계단 등의 실제 표시 모델을 반투명하게 미리 볼 수 있다. 정면 화살표와 회전 각도를 함께 표시하며 R로 돌리면 미리보기와 설치 방향에 똑같이 반영된다.
- 점유 공간이 겹치거나 격자 범위를 벗어나면 미리보기를 빨간색으로 표시하고 배치를 막는다. 좌표 변경·회전·JSON 불러오기에도 같은 검사를 적용한다.
- 복제를 누르면 종류와 방향을 유지한 복제본을 놓을 위치를 직접 고른다. 원본 층을 상속하지 않으며, 높이는 가리킨 표면을 따른다. 삭제·실행 취소·다시 실행도 사용할 수 있다.
- 배치 높이를 바꾸고 그보다 위에서 시작하는 오브젝트를 숨긴다.
- 진영별 작업 공간을 전환하고, 브라우저 자동 저장 또는 JSON 파일 저장·불러오기를 사용한다.
- 폭이 좁은 창에서는 속성 패널 버튼으로 패널을 펼치거나 접는다.

표면 스냅은 배치 위치를 정하는 조작 보조다. 지지 가능 여부 같은 게임 규칙을 판정하지 않는다. 자동 배치에서는 가리킨 윗면 높이를 사용하고, 윗면이 없으면 바닥 0층에 놓는다. 선택한 표시 높이보다 낮은 표면에도 놓을 수 있다. Shift를 누를 때만 지정 높이에 고정한다. 숨긴 오브젝트는 스냅 대상에서 제외하며, 길은 바닥 장식으로 취급한다. 위층 숨김 중 더 높은 표면에 배치하면 새 오브젝트가 보이도록 표시 높이도 따라 올라간다.

현재는 **실제 카탈로그를 연결한 배치 프로토타입**이다. 이름·점유 크기·출입구·진영·식물 정보는 설치본에서 추출했고 도형은 자체 제작한 단순 표현이다. 원격 최신 게임 버전을 자동 추적하지 않는다. 회전된 점유 직육면체의 겹침과 격자 경계를 검사하며, 지지 구조·출입구·연결 규칙 등 게임의 건설 가능 여부는 아직 판정하지 않는다. 플랫폼 등도 빈 공간 예외 없이 보수적으로 전체 점유 범위를 사용한다. 검사에 걸리지 않았다는 것이 게임에서 건설 가능하다는 뜻은 아니다.

길 연결은 원본 경로 데이터를 사용한 계획용 참고 검사다. 실제 지지 구조·지형·통행 장애물·이동 거리·구역 경계/소속·일터의 자원 접근 범위는 판정하지 않는다. **초록색은 길 그래프상 연결이라는 뜻이지 게임에서 건설·운영 가능하다는 보증이 아니다.** 숨긴 층도 연결 계산에 포함한다. 겹침·경계 오류가 있는 기존 저장본의 해당 오브젝트는 경로에서 제외하고 오류로 표시한다.

실제 카탈로그의 상단 스냅은 확인된 주거·창고·플랫폼·산업용 더미에만 적용한다. 탱크·일반 더미·계단·길·식물은 상단 스냅 대상이 아니다. 식물을 놓을 때는 바닥 0층을 사용하며 Shift로 계획 토양 높이를 지정할 수 있다. 토양 여부는 검증하지 않는다. 길은 높이 0.12로 그리되 원본 점유 높이 1을 예약하고, 계단은 1층을 오르지만 2층 공간을 예약한다. **배치 시작 높이 0–12는 편집기 임시 한도이며 게임 최대치가 아니다.** 바닥 크기만 게임의 기본값·범위를 반영했으며 지형과 직사각형 맵은 지원하지 않는다.

이전 브라우저 저장본에 이미 겹친 항목이 있으면 자동으로 삭제하지 않고 빨간 테두리와 경고로 표시한다. 좌표를 바꾸거나 삭제해 정리할 수 있다. 새 JSON 불러오기에서 겹침이나 범위 문제가 발견되면 현재 설계를 유지하고 불러오기를 중단한다.

브라우저 저장은 해당 브라우저·주소에만 남는다. 파일로 보관하거나 에이전트와 주고받을 때는 **청사진 저장**으로 JSON을 내려받는다. 좌표·회전과 파일 형식은 [설계 데이터 설명](docs/DATA_FORMAT.md)을 참고한다.

## 구현과 확인

작은 로컬 웹 앱으로 시작한다. TypeScript, Vite, Three.js를 사용하며 별도 서버나 AI 서비스 연결은 없다.

```powershell
npm.cmd run build
npm.cmd test
```

브라우저 테스트는 설치된 Microsoft Edge를 사용한다. 배치·편집·파일 왕복, 층 숨김, 진영별 작업 보관, 좁은 화면을 확인한다. 테스트 도구에 대한 실행 설정은 `playwright.config.ts`에 있다.

## 설치본 데이터 갱신

게임은 읽기 전용으로 접근한다. 모델·텍스처·설명문을 복사하지 않고 필요한 사실 데이터만 추출한다. 전체 자료는 `data/game-catalog.json`(338개 정의, 보조 정의 4개 제외), 웹용 초기 목록은 `src/generated/active-catalog.json`이다. 게임 설치 없이도 생성된 JSON으로 웹을 실행할 수 있다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/export-game-catalog.ps1 -GamePath 'C:\Program Files (x86)\Steam\steamapps\common\Timberborn'
npm.cmd run catalog:select
```

두 명령은 각각 성공 여부를 확인한다. 원본 버전·해시가 바뀌면 웹 목록 생성은 중단된다. 변경 내용을 검토하고 프로필·호환성을 결정한 뒤 명시적으로 갱신한다. 전체 자료에 있는 모든 종류가 현재 배치 가능한 것은 아니다. 다음 확장 범위는 사용 피드백으로 정한다.
